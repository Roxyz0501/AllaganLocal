# Allagan Local

作者: Roxyz0501。新規の独立Dalamudプラグインです。

## データ取得元

- **Allagan Tools（InventoryTools）**：所持品・所持金の取得に必要です。
- **AllaganMarket**：マーケット販売履歴を使う場合に必要です。

取得元プラグインがデータを記録・保存することが前提です。導入しただけでは未記録の情報は表示できません。設定の「データ取得元プラグイン」に、未導入／導入済み・停止中／導入済み・稼働中とバージョンを表示します。停止中でも保存済みの記録は閲覧できます。

## 公開プレビュー版の導入

共有カスタムリポジトリをDalamudに登録して Allagan Local をインストールできます：`https://raw.githubusercontent.com/Roxyz0501/DalamudPluginRepo/main/repo.json` 。以下は開発用としてZIPから導入する場合の手順です。

1. ZIPの内容を専用フォルダーへすべて展開します。DLLだけでなく `web` と `runtime` も必要です。
2. Dalamudの開発用プラグイン設定で `AllaganLocalPlugin.dll` を登録します。
3. プラグインの設定、または `/allaganlocal` を開き、「サイトを開く」を押します。

「読み込み時にサイトを起動」は初期状態でONです。プラグイン読込時にサーバーが自動起動します。「再起動」は稼働中のサーバーを停止して起動し直し、停止中なら起動します。ブラウザーを自動で開くことはありません。既存のサイトが起動中ならそれを利用します。自分で起動したサーバーだけを、プラグイン終了時に停止します。Windowsの定期タスクは作成しません。

新規環境ではサイトの「接続・データ設定」でアイテム辞書を更新してください。既存データを利用する場合は、プラグイン設定に既存サイトの **dataフォルダー** を指定して保存し、既存サーバーを終了してプラグインを再読み込みします。複数のサーバーで同じ保存先を同時に使わないでください。

## 言語・キャラクター設定

日本語・英語・ドイツ語・フランス語・韓国語・中国語簡体字・繁体字の表示切替を用意しています。ゲーム内のアイテム名は日本語辞書です。一部の詳細説明やエラーには日本語が残ります。各地域版ゲームでの同一Dalamudビルドの動作を保証するものではありません。

メインキャラクターはキャラクター画面の「メイン」タグで設定します。特定のキャラクター名やIDの固定指定はありません。タグとサイト側の言語選択は利用中のブラウザーに保存されます。
